# API Contract

The backend exposes a REST API for the frontend to read and modify resources.
All endpoints return JSON. Base URL is `http://localhost:3000` in development.

---

## 1. Get all resources

**`GET /resources`**

Returns every resource in the database, sorted by like count descending.

### Response — 200 OK

```json
[
  {
    "id": "abc-123",
    "title": "Intro to REST APIs",
    "subject": "Web Development",
    "url": "https://example.com/rest-intro",
    "note": "Great starter video",
    "likes": 18,
    "dislikes": 3,
    "createdAt": "2026-07-14T10:00:00Z"
  }
]
```

For any item with an uploaded file, `fileUrl` is a freshly generated, time-limited presigned S3 URL (regenerated on every `GET /resources` call, so it never goes stale).

---

## 2. Create a resource

**`POST /resources`**

Adds a new resource. Called from the Add Resource form. A resource needs a `url`, a file, or both — subject is free text (no fixed list).

### Request body — link only (`application/json`)

```json
{
  "title": "Intro to REST APIs",
  "subject": "Web Development",
  "url": "https://example.com/rest-intro",
  "note": "Great starter video"
}
```

### Request body — file (or file + link) upload (`multipart/form-data`)

Fields: `title`, `subject`, `note` (optional), `url` (optional), `file` (the binary upload). Sent as `multipart/form-data` since it includes a binary file.

### Response — 201 Created

```json
{
  "id": "abc-123",
  "title": "Intro to REST APIs",
  "subject": "Web Development",
  "url": "https://example.com/rest-intro",
  "note": "Great starter video",
  "likes": 0,
  "dislikes": 0,
  "createdAt": "2026-07-14T10:00:00Z"
}
```

### Error — 400 Bad Request

Returned when the payload fails validation (see `docs/validation.md`).

```json
{ "error": "Title is required" }
```

---

## 3. Like a resource

**`POST /resources/:id/like`**

Increments the like count for a resource. No request body needed.

### Response — 200 OK

```json
{ "id": "abc-123", "likes": 19, "dislikes": 3 }
```

### Error — 404 Not Found

```json
{ "error": "Resource not found" }
```

---

## 4. Dislike a resource

**`POST /resources/:id/dislike`**

Increments the dislike count. Same shape as the like endpoint.

### Response — 200 OK

```json
{ "id": "abc-123", "likes": 18, "dislikes": 4 }
```

### Error — 404 Not Found

```json
{ "error": "Resource not found" }
```

---

## Notes

- All endpoints return `Content-Type: application/json`.
- `id` is a UUID string generated by the backend on create.
- `createdAt` is an ISO 8601 timestamp in UTC.
- Errors always return `{ "error": "message" }`.
- The `/health` endpoint (`GET /health`) is also available and returns `{ "status": "ok" }` — used for load balancer health checks in Sprint 4.
